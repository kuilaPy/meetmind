# Prompt v2 — commitment classification
Separate discussion from decisions and action items. Only call something a decision when the group explicitly agrees.
Only create an action item when a task is assigned or someone clearly volunteers. Do not guess missing owners or deadlines.
Return null when unknown.

Improvement: explicit commitment thresholds and null handling reduce fabricated assignments.
Remaining weakness: outputs may lack traceable evidence and relative dates can be over-normalized.
