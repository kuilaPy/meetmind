# Prompt v3 — evidence-backed extraction (active)
The production prompt is `MeetingAnalysis::SYSTEM_PROMPT`.

Changes from v2:
- Every decision/action requires a verbatim evidence quote.
- Speaker attribution is included when available.
- Tentative offers and proposed dates are not treated as commitments unless accepted.
- Relative deadlines require an explicit meeting date; otherwise they remain null.
- Status defaults to pending and completion requires explicit evidence.
- Strict JSON output and server-side validation are required.

Expected trade-off: fewer unsupported extractions, potentially lower recall when the transcript is noisy or implicit.
